📦 Exportation Professionnelle du Réseau Routier

Exportez votre réseau routier 3D dans les formats standardisés de l'industrie pour les simulateurs de conduite autonome, de trafic ou les moteurs 3D.

🚗 ASAM OpenDRIVE (.xodr)
Format standard pour simulateurs de conduite autonome (CARLA, Apollo, BeamNG, VIRES VTD).
🚦 Eclipse SUMO (.net.xml)
Réseau de trafic microscopique pour le simulateur open source SUMO avec feux tricolores et priorités.
🗺️ GeoJSON GIS (.geojson)
Format géospatial universel multi-couches pour QGIS, ArcGIS, Mapbox et analyse cartographique.
🎨 Modèle 3D Wavefront (.obj + .mtl)
Maillage surfacique triangulé 3D avec matériaux PBR pour Blender, Unreal Engine 5 et Unity.
