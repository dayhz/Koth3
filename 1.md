---

# PRINCIPLE FONDAMENTAL

Le monde doit être généré à partir de données et de relations logiques.

Le moteur ne doit jamais fonctionner comme une simple scène 3D composée d'objets positionnés manuellement.

La géométrie logique doit être la source de vérité.

Le rendu 3D doit être une représentation de cette géométrie.

Exemple :

Road → Intersection → Lane → Sidewalk → Markings

et non :

Mesh de route → Mesh de panneau → Mesh de trottoir placés indépendamment.

---

# RÈGLE ABSOLUE

Aucun élément ne doit être placé arbitrairement lorsque sa position peut être calculée à partir de son contexte.

Par exemple :

Un futur panneau STOP ne devra pas être positionné avec :

x = ...
y = ...
z = ...

Il devra être associé à une règle STOP, elle-même associée à une approche d'intersection, puis sa position et son orientation devront être calculées automatiquement.

Même principe pour :

* feux ;
* passages piétons ;
* marquages ;
* trottoirs ;
* bâtiments ;
* accès ;
* stationnement.
